# Hurricane
Hurricane is a Spigot/Paper plugin that has an unofficial Fabric/NeoForge port.

This plugin/mod provides various workarounds for Geyser players that modify the server in order to achieve better playability.

Issues with each workaround are listed in the Hurricane plugin/mod config. 

**Please take your time to read them as the workarounds in this plugin/mod can be used for exploitative purposes.**

## Features {#features}
- Fixes bamboo and dripstone collision for Geyser players by setting them to no server-side collision.
- Provides a config option to suppress "Mismatch in destroy block pos" warnings. (Only available on Fabric/NeoForge!)

## Compatibility {#compatibility}
- Spigot/Paper 1.14.x - 26.2
- Fabric/NeoForge 26.2
