---
title: Custom Resource Packs
description: How to use custom resource packs for Geyser.
---

Geyser supports custom resource packs for use with custom items, blocks, and skulls. See:

- [Custom items](/wiki/geyser/custom-items)
- [Custom blocks](/wiki/geyser/custom-blocks)
- [Custom skulls](/wiki/geyser/custom-skulls)
- [Custom waypoint icons](/wiki/geyser/custom-waypoints)
- [Custom entities](/wiki/geyser/custom-entities)

:::info
Geyser does not convert resource packs from Java Edition automatically.
However, you can use automatic tools such as [Rainbow](/wiki/other/rainbow/) or [Thunder](/wiki/other/thunder) to make converting content simpler.
:::
